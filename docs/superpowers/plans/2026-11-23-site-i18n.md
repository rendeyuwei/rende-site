# rende-site 中英文实施计划（2026-11-23）

依据：`docs/superpowers/specs/2026-11-23-sites-i18n-design.md`。只改本仓库。

## 分解检查

- **Blocking first steps**：先定 `src/shell/lang.ts` 的数据形状（`RfSite` 站点表、`RfPlace`、`window.rfLang` 接口）。顶栏、页面、构建、测试都依赖它。
- **Independent workstreams**（`lang.ts` 定稿后）：英文页 `public/en/index.html`；顶栏文案与切换器；构建脚本拼接与内联。三者只通过 `window.rfLang` 和 `data-rf-site`、`data-rf-enter` 属性相连。
- **Shared mutable state**：`localStorage["rf-lang"]` 与 cookie `rf-lang`（同源四站共享）；`location`（只用 `replace` 和 `href`）；`window.rfLang`（按 `v` 只装一次）。不新增其他全局状态。
- **Smallest safe decomposition**：①语言模型与测试 → ②构建接入（`topbar.js` 拼接 `lang.js`、中文页内联）→ ③顶栏双语与切换器 → ④英文页与中文页 SEO 头 → ⑤文档。每步都能单独跑 `npm test`。

## 步骤

### 1. 语言模型 `src/shell/lang.ts`（新建）
- 顶层全局类型 `RfLangCode`、`RfSite`、`RfPlace`、`RfLangApi`、`Window.rfLang`。
- IIFE 内实现 `place / match / pref / choose / offers / href / siteHref / enter`；`currentScript` 带 `data-rf-enter` 时执行 `enter()`。
- 测试（`test/site.test.mjs` 新增 `describe("lang")`）：
  - 首访 `['en-US']` → `/en/`；`['zh-CN']` 不动；`['ja','en','zh-CN']` → `/en/`；`['ja','zh-TW','en']` 不动；`['ja','ko']` 与空列表 → `/en/`。
  - 偏好 `zh` + 浏览器 `en` 不动；偏好 `en` + 浏览器 `zh` → `/en/`。
  - `/en/` + 偏好 `zh` 不动；`/?lang=zh` + 浏览器 `en` 不动。
  - `/?freeze=0#about` → `/en/?freeze=0#about`。
  - 页面未声明英文对应页不跳。
  - `localStorage` 与 cookie 均抛错时 `enter()`、`choose()` 不抛错，`choose()` 返回 `false`。
  - `href()`：`/en/?a=1#x` → `/?a=1&lang=zh#x`；`/recipes/en/12` ↔ `/recipes/12`；`/easypic` 归 easypic。

### 2. 构建 `scripts/copy-static.mjs`
- 读取 `dist/shell/lang.js`；把它拼到 `dist/shell/topbar.js` 前面（已拼过就跳过）。
- 把 `dist/index.html` 中的 `<script data-rf-enter src="/shell/lang.js"></script>` 替换为内联脚本；找不到占位或脚本里含 `</script` 时构建失败。
- `required` 增加 `en/index.html`、`shell/lang.js`。
- 测试：dist 合约包含新文件；中文页内联 `enter`，不再引用外链 `lang.js`；`topbar.js`、`lang.js`、`motion.js` 均 < 12,000 字节且无 import/export。

### 3. 顶栏 `src/shell/topbar.ts`、`public/shell/topbar.css`
- `TOOLS` 改为中英文案；当前工具改由 `rfLang.place()` 判断（保留 `data-tool`）；链接走 `siteHref()`；同时改写页面中的 `a[data-rf-site]`。
- 切换器 `.rf-lang`（`offers()` 为真时显示），点击 `choose()` 并更新 `href`。
- 色块 `aria-hidden`；`.rf-bar` 设置 `lang`；CSS “当前”增加 `:lang(en)` 版本；`.rf-lang` 复用按钮样式。
- 测试：沿用现有三条；新增英文页文案与链接、旧子站不显示切换器、存储禁用时追加 `?lang=zh`、切换器点击写偏好并带 query/hash。

### 4. 页面
- `public/index.html`：head 增加 canonical/hreflang 与 `data-rf-enter` 占位；三张工具卡加 `data-rf-site`。中文文案不变。
- `public/en/index.html`（新建）：结构与中文页一致，英文文案、`lang="en"`、canonical/hreflang；不内联 `enter`。
- 测试：两页结构骨架一致；英文页可见文字和 alt/aria/title/description 中除 `lang="zh-CN"` 元素和 `aria-hidden` 装饰外没有汉字；两页 meta 信息正确。

### 5. 文档
- `README.md`、`README.zh-CN.md`：`en/`、`/shell/lang.js` 契约与子站接入方式。

## 验证
- `npm run lint`、`npm test`。
- 本地 `npm run preview`，用系统 Chrome（puppeteer-core 装在仓库外）验证：首访三种语言顺序、无匹配、手选覆盖、英文链接不被覆盖、存储禁用（脚本模拟抛错）、query/hash、无循环、禁 JS 可读、手机英文无横向溢出；截取桌面/手机中英 4 张图。

## 自查一致性
- 规则 1–7 与 spec 第 1 节一一对应：URL（步骤 1/4）、优先级与默认英文（步骤 1 `enter`）、仅手选持久化（`choose` 只在切换器调用）、存储禁用（`siteHref` 追加 `lang=zh`）、无循环（只有无前缀 → `en/`）、保留 query/hash/路由（`href`）。
- 子站 `en` 全为 `false`：主站英文页指向中文子站入口，不会出现 404；旧子站页面没有对应页声明，不显示切换器、不跳转。
- 预览只用本分支构建的 `/shell/*.js`，不依赖线上顶栏。
